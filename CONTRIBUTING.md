# Como contribuir · Contributing

Obrigado pelo interesse! Os apps FeatherWorks são escritos em Rust, com interface nativa no
[pelicano](https://github.com/feather-works/pelicano). Cada app tem seu repositório; quando o
repositório tem um `CONTRIBUTING.md` próprio, ele vale no lugar deste.

## Defeitos e sugestões · Bugs and ideas

Abra uma issue pelos modelos **Defeito** ou **Sugestão** no repositório do app. Para defeito,
conte os passos, a versão e o sistema, e cole o console (**F12**) se houver erro. Não anexe
arquivos com dados pessoais. Falha de segurança: veja o [SECURITY.md](SECURITY.md).

Open an issue with the **Bug** or **Feature request** form in the app's repository.

## Regras do projeto · Project rules

- **Privacidade:** sem conta, sem login, sem telemetria. Nada do conteúdo do usuário sai da máquina.
- **Todas as línguas:** texto novo de interface e da ajuda F1 entra em pt-BR, en-US e es-ES.
- **Nada de item de menu sem função.** Se não está implementado, não entra no menu.
- **Código próprio:** não copie código de outro projeto, mesmo com licença permissiva.
- **Mudança de desempenho vem medida**, antes e depois.
- Commits pequenos, com mensagem explicando o porquê; a correção de uma issue fecha com `Fixes #N`.
